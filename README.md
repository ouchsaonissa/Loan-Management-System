Final DevOps Project - Loan Management System for Group 6.

## Project Goal

Build a small, complete, working Loan Management System using:

- Spring Boot backend REST API
- React frontend with Vite and Axios

The project will be built step by step. The first priority is a local working application before adding Docker, CI/CD, monitoring, Terraform, or deployment files.

## Development Rules

- Keep the project simple and working.
- Build one small step at a time.
- Backend code must stay inside `backend/`.
- Frontend code must stay inside `frontend/`.
- Backend will use Spring Boot REST API.
- Frontend will use React Vite and Axios.
- Database will use MySQL.
- Database credentials should come from environment variables.
- Do not use Thymeleaf.
- Do not add JWT, Kubernetes, Redis, ELK, email, or PDF export unless requested later.
- Finish the local working application before Docker, CI/CD, monitoring, and Terraform.
