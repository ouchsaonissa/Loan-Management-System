# AGENTS.md

Project: Loan Management System - Group 6

Read the project flow first:
docs/Loan_Management_System_Project_Flow_Group6.txt

Main goal:
Build a small complete working Loan Management System using Spring Boot backend and React frontend.

Important rules:
1. Keep the project small and working.
2. Backend must be inside backend/.
3. Frontend must be inside frontend/.
4. Backend uses Spring Boot REST API.
5. Frontend uses React Vite and Axios.
6. Do not use Thymeleaf.
7. Do not add JWT, Kubernetes, Redis, ELK, email, or PDF export unless asked later.
8. Finish local working app first before DevOps.
9. Use MySQL.
10. Use environment variables for database credentials.
11. Each change should be small and easy to commit.
12. Do not build everything at once.
